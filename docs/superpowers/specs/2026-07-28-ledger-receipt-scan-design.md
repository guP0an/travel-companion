# 丸玩账本小票识别设计

日期：2026-07-28

## 目标

在当前行程的账本中增加“拍小票”和“上传图片”两个入口。系统识别小票后，只把结果预填到记账表单；用户可以修改全部识别结果，并且必须主动点击“确认记账”后才写入账本。

首版一次只处理一张图片，优先解决旅行中最常见的快速记账场景。

## 已确认的体验

1. 用户在当前行程的账本中选择“拍小票”或“上传图片”。
2. 页面显示小票缩略图和“正在识别小票”状态。
3. 识别完成后预填以下现有账本信息：
   - 金额
   - 消费日期
   - 分类：餐饮、交通、门票、住宿、购物、其他
   - 商家与识别摘要，写入可编辑的备注
4. 用户可以修改分类、金额、日期和备注。
5. 只有用户点击“确认记账”后，账目和原始小票图片才保存到当前行程。
6. 如果没有认清，保留图片并提示“没认清，可以手动填写”，用户仍可手动完成记账。

选择另一张图片时重新识别并替换机器预填结果。移除图片时保留当前表单内容，避免丢失用户已经修改的文字。

## 方案选择

采用“小票专用识别 + 复用现有账本流程”：

- 在现有 `/api/ai` 中增加小票识别操作，继续使用现有 Kimi 视觉模型、登录校验和错误处理。
- 前端继续使用现有账本表单和 `addExpense` 保存流程。
- 原始图片继续使用现有私有 `expense-receipts` 存储，不新建公开图片地址。
- 消费日期复用现有 `spent_at` 字段；商家写入备注，不新增数据库字段。

没有选择以下方案：

- 复用行程截图识别格式：字段与小票不匹配，后续校验容易混乱。
- 新增第三方 OCR 服务：会增加供应商、密钥和隐私成本，现有视觉模型已经能覆盖首版。
- 本地 OCR 加规则：对中文、日文和不同版式小票的金额识别不够稳定。

## 组件与数据流

### 账本界面

`Ledger` 保留原有手动记账能力，并增加：

- “拍小票”：使用系统相机，优先调用后置摄像头。
- “上传图片”：从相册或文件中选择图片。
- 小票缩略图、识别中状态和失败提示。
- 可编辑的消费日期输入。
- “确认记账”按钮；识别完成不会自动保存。

识别过程只更新当前页面状态，不写数据库。保存时仍调用现有 `addExpense`，并带上当前 `itinerary_id`，确保日本行程的小票不会进入香港行程账本。

### 图片识别

前端沿用现有图片压缩限制，把单张图片发送给 `/api/ai` 的小票识别操作。服务端要求模型返回结构化结果，并在返回浏览器前统一清洗：

```ts
{
  amount: number | null
  spentAt: string
  category: '餐饮' | '交通' | '门票' | '住宿' | '购物' | '其他'
  merchant: string
  note: string
  confidence: 'high' | 'medium' | 'low'
}
```

校验规则：

- 金额必须是有限的正数，否则返回 `null`。
- 日期必须是 `YYYY-MM-DD`，不能确定时留空。
- 分类必须来自现有六种分类，否则归为“其他”。
- 商家和备注限制长度，忽略模型返回的额外字段。
- 低置信度时提示用户重点核对金额和日期，不阻止编辑或保存。

商家和摘要在前端组合到备注输入框中，因此不需要修改账本表结构。

### 保存与隐私

- 用户确认前，图片只保留在当前浏览器页面中。
- 用户确认后，账目写入当前行程，小票上传到现有私有存储。
- 识别接口继续要求登录，不能匿名调用。
- 只接受 JPEG、PNG、WebP；沿用现有图片大小和压缩限制。
- 识别失败不上传、不自动创建账目，也不清空用户已经填写的内容。

## 错误处理

- 图片类型或大小不合规：在本地提示并停止识别。
- 模型超时、接口失败或返回格式错误：保留图片，切换为手动填写。
- 金额或日期可信度较低：显示核对提示，字段仍可编辑。
- 保存失败：保留表单和图片，允许用户再次点击确认，避免重复填写。
- 保存成功：清空表单和图片，并刷新当前行程的账目列表。

## 验收标准

1. 手机端可以直接拍摄一张小票，也可以从相册上传一张图片。
2. 识别结果能预填金额、日期、分类和包含商家的备注。
3. 所有预填字段均可修改，识别完成不会自动产生账目。
4. 点击确认后只新增一条账目，并且归属当前行程。
5. 确认后可以打开该账目的私有小票图片。
6. 识别失败时可以保留图片并手动记账。
7. 接口拒绝未登录请求、非法图片类型和无效模型输出。
8. 原有不上传图片的手动记账流程保持可用。

## 首版不做

- 多张小票批量识别
- 小票逐项商品明细
- 发票真伪校验
- 自动换算汇率或多币种账本
- 未经用户确认自动记账
- 重复小票检测

这些能力只在真实使用表明有需要时再增加。
