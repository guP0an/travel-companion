## 一句话

一个**陪你走完每一程、还记得你走过哪儿**的 AI 旅行管家——**行前帮你排，行中陪你走，行后替你记**。
有性格（管家「丸丸」，用 lord 本人的声音）、懂你脾气、记得你。

## 我们和「直接问 AI」的区别（护城河）

通用 AI 是**一个瞬间**（行前问一下就走，不记得你）；我们是**一段关系**（陪完整程 + 把每趟旅行沉淀成记忆）。差异建在四层：**成品化 · 陪伴 · 记忆 · 社交**。完整论证见 [08](08-travel-lifecycle-and-moat.md)。

## 三大模块 × 旅行全周期

| 模块（能力块） | 生命周期（时间轴） | Phase |
|----------------|--------------------|-------|
| ① 行程规划（提问引导式管家） | 行前 · 规划 | **Phase 1（当前）** |
| ③ 中国记忆地图 + 游记 | 行后 · 记忆 | Phase 2 |
| ①延伸 + 实时地图/周边 + 语音陪伴 | 行中 · 陪伴 | Phase 2 起 |
| ② 论坛/朋友圈（社交） | 行后 → 社交 | Phase 3 |

> 飞轮：行中打卡 → 行后游记+点亮地图+反哺偏好 → 管家更懂你+喂养社交 → 行前更准。越转越强、别人复制不了。

## 关键决策（已拍板）

- **技术栈**：React + Vite + TS + Tailwind；前端 → serverless 代理藏 Key → LLM。
- **模型供应商**：**DeepSeek（永久）**，OpenAI 兼容，`deepseek-chat`。强制 JSON 用 `response_format: json_object` + prompt 描述结构 + 代理侧二次校验。
- **导出带图**：结果页可导出竖版分享卡（PNG）/ PDF，纯前端，兼增长钩子。配图走真实图库/POI，**不用 AI 生成、不爬小红书**。
- **声音**：管家用 **lord 本人音色克隆**（本人授权）。Phase 2/3、需小程序/App。
- **MVP 纪律**：Phase 1 只交付「行前 ①」并打磨到有灵魂，不范围爆炸。

## 当前进度（2026-06-13）

**已实现（Phase 1 可跑，`localhost:5173`）**：
- 工程：React + Vite + TS + Tailwind v4。
- 生成：DeepSeek 真生成行程（serverless 代理藏 Key）。
- 账号/云存储：Supabase Auth(邮箱) + Postgres（itineraries 表）；收藏 + 我的行程查看页。
- 丸丸：原创小丸子吉祥物（蹦跳动画）+ Lv 成长标记；一串丸子生成按钮。
- 上传图：截图 OCR(Tesseract) → DeepSeek 结构化提取（票务/酒店）→ 可编辑表单 → 据此排程。
- 地图入口：每条景点跳高德；当前位置「你现在在 X」。
- 账本：消费记录（分类/金额/备注/总额/流水），expenses 表。
- 手动编辑行程：改/加/删条目、改每日主题。
- 导出：保存图片（分享卡）。
