# 13. 移动端布局与微信登录设计

状态：已实现，待生产参数与真机验收
日期：2026-07-27

## 1. 目标

本阶段聚焦两件事：

1. 让手机用户在首屏快速完成行程输入，不再先阅读一整段桌面式介绍，也不再看到占满一屏的空行程区域。
2. 把现有微信小程序登录基础接成完整可用的授权登录流程，使行程、账本和票据归属于同一个用户。

## 2. 移动端体验

### 2.1 生成前

- 保留丸丸品牌栏和登录入口，但缩短高度并控制横向信息量。
- 将产品介绍压缩为短标题和一句说明，行程输入成为首屏主任务。
- 缩小表单区的垂直间距，使目的地、天数、节奏、截图上传和主按钮尽量在首屏内完成。
- 未生成行程时不渲染完整的 `YOUR TRIP` 空页面，仅保留必要的轻量提示。

### 2.2 生成后

- 行程生成成功后自动定位到结果区域。
- 结果页优先展示日期、天气、日程和风险提醒。
- 保留明确的“调整行程”入口，返回原输入状态继续修改。
- 手机端底部操作区不得遮挡正文，并适配安全区。

### 2.3 桌面端

- 保持现有左右双栏结构，不因本次移动端调整产生明显回归。

## 3. 微信登录

### 3.1 本阶段实现

本阶段实现微信小程序内的一键授权登录：

1. 用户在小程序点击“微信登录”。
2. 小程序调用 `wx.login` 获取一次性 `code`。
3. 丸丸服务端使用 AppID 和 AppSecret 向微信换取 `openid`、`unionid` 和 `session_key`。
4. 服务端使用不可逆摘要查找或创建微信身份映射，并关联 Supabase 用户。
5. 服务端签发 Supabase 可接受的短期访问令牌。
6. 小程序建立会话，并用该会话读写用户行程、账本和票据。

### 3.2 安全约束

- AppSecret、Supabase 管理密钥和 JWT 私钥只保存在服务端环境变量中。
- 客户端不得保存或上传 `session_key`。
- 数据库不保存明文 `openid`、`unionid`，仅保存带服务端 pepper 的摘要。
- 登录接口继续使用来源校验、频率限制、超时和统一错误信息。
- 用户取消授权、微信接口失败、令牌过期时必须可重试，不得进入半登录状态。

### 3.3 网页扩展实现

- 微信内 H5 使用公众号网页 OAuth，授权完成后通过 Supabase Magic Link 建立标准网页会话。
- PC 网页使用微信开放平台网站应用扫码，扫码确认后回到原页面。
- 两者复用小程序的微信身份映射和现有 Supabase 数据，但使用各自独立的 AppID/AppSecret。
- 对应平台参数未配置时不显示微信入口。

## 4. 配置依赖

正式启用小程序登录需要：

- 真实微信小程序 AppID 与 AppSecret。
- 微信公众平台中配置 `wanwantrip.online` 为合法 request 域名。
- Vercel 中配置微信、Supabase 和 JWT 签名所需的服务端环境变量。
- 小程序工程使用真实 AppID，不再使用 `touristappid`。
- 已认证公众号 AppID/AppSecret，并配置 `wanwantrip.online` 为网页授权域名。
- 已审核的微信开放平台网站应用 AppID/AppSecret，并配置 `wanwantrip.online` 为回调域名。
- Vercel 配置 OAuth state 签名密钥和固定生产来源。

缺少上述生产参数时，代码可以完成并通过自动化测试，但真机授权无法完成最终验收。

## 5. 测试与验收

- 移动端 375px、390px、430px 宽度下，主输入流程首屏可见且无横向滚动。
- 未生成行程时不出现大型空结果区。
- 生成后可自动进入结果并返回调整，输入状态不丢失。
- 桌面端布局无回归。
- 微信登录覆盖成功、用户复用、微信错误、取消/失败、过期令牌和限流场景。
- 真机环境验证登录后能够跨页面访问同一用户的行程、账本和票据。

## 6. 发布策略

先完成代码、自动化测试和移动端视觉检查，再配置生产密钥进行真机联调。生产参数未齐备时，登录页应明确显示暂不可用状态，不提供虚假的成功反馈。

## 7. 实现记录

- 移动端在宽度不超过 820px 且尚未生成行程时隐藏完整空结果区，桌面端不受影响。
- 规划标题、说明、天数、节奏、截图上传、主按钮和状态区的手机端间距已收紧。
- 小程序只接受未过期的本地会话，过期记录会立即删除。
- 小程序业务请求可通过 `getAuthorizationHeader()` 获取 `Authorization: Bearer <token>`。
- 自动化测试覆盖移动端布局契约、小程序登录成功、缓存复用、过期清理、失败提示和服务端身份安全。
- 网页按微信内/普通浏览器显示一个环境感知登录入口，OAuth 回调校验签名 state、HttpOnly Cookie 和同站回跳地址。
- 微信网页身份通过 Supabase Admin Magic Link 交接为现有网页会话，不增加第二套会话系统。
