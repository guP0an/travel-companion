# 06 · 管家提问库（提问引导式问题清单）

> 状态：草稿 · 2026-06-13 · 作者：赛巴斯蒂安 + lord
> 本文是管家「提问引导式」收集信息时**要问哪些问题**的总清单。
> 配套：[05-butler-prompt-design.md](05-butler-prompt-design.md)（怎么问 = 对话 prompt）、[04-architecture-and-data-model.md](04-architecture-and-data-model.md)（答案存哪 = 数据模型）。

---

## 0. 设计原则（先读，别变成查户口）

问得多 ≠ 懂你。这份清单是「**可问的全集**」，不是「每次都全问」。管家的纪律（见 [05 §3.2](05-butler-prompt-design.md)）：

1. **一次只问一两个**，像朋友聊天，不连珠炮、不像填表。
2. **能推断的别问**（「下个月去玩四五天」→ 不再追问天数）。
3. **核心齐了就主动提议生成**：「我先给你排一版，边看边调」——剩下的可选项边聊边补。
4. **优先级**：必问 → 体验核心 → 锦上添花。token/耐心有限时，从下往上砍。
5. 选项用 **chip 点选**为主、自由文本兜底，降低用户打字负担。

---

## 1. 必问（缺了排不了）

| 问题（管家口吻示例） | 收集字段 | 选项 / 形式 | 怎么用 |
|----------------------|----------|-------------|--------|
| 想去哪儿玩？ | `destination` | 自由文本 | 行程主体 |
| 待几天？ | `days` | 数字 1–15 | 决定 Day 数 |
| 大概什么时候出发？（不确定也没事） | `departureDate` | 日期 / 跳过 | 推断季节、给天气与穿衣提示 |

---

## 2. 体验核心（决定「懂不懂你」，强烈建议问）

| 问题（管家口吻示例） | 收集字段 | 选项（chips） | 怎么用 |
|----------------------|----------|---------------|--------|
| 想玩得紧凑点多看几处，还是溜达一些慢慢晃？ | `pace` | 紧凑(多看) / 适中 / 溜达(躺平) | 控制每天景点密度与赶路强度 |
| 早起没问题，还是想睡到自然醒？ | `travelerTags` | 早起鸟 / 懒觉党 | 决定每天起始时间，懒觉党不排早场 |
| 这趟你最看重啥？挑几个。 | `travelerTags` | 历史人文 / 自然风光 / 美食 / 购物 / 小众宝藏 / 网红打卡 / 夜生活 | 选点的口味权重 |
| 怕排队吗？ | `travelerTags` | 怕排队 / 不在乎 | 触发错峰提醒、避开高峰时段 |
| 这趟是一个人，还是和谁一起？ | `companions` | 独自 / 情侣 / 朋友 / 带爸妈 / 带娃 | 影响强度、选点与节奏（带老人/娃更松） |

---

## 3. 锦上添花（问得到更贴心，问不到不阻塞）

| 问题（管家口吻示例） | 收集字段 | 选项 / 形式 | 怎么用 |
|----------------------|----------|-------------|--------|
| 有没有非去不可的地方？某个景点、某家店，我一定排进去。 | `mustVisit` | 自由文本（可多个） | 强约束：必须出现在行程里 |
| 有没有特别不想去的、或踩过雷的？我帮你避开。 | `avoid` | 自由文本 | 负约束：生成时回避 |
| 预算大概什么档？说个数或「适中」都行。 | `budgetTier` / `budgetNote` | 穷游 / 适中 / 舒适 / 具体金额 | 选点与餐饮档次 |
| 走路多你介意吗？还是尽量少折腾、多打车？ | `travelerTags` | 走得动 / 尽量少走 / 打车为主 | 路线紧凑度、交通建议 |
| 住的地方定了吗？定了告诉我大概位置。 | `travelerNote` | 自由文本 | 按住处就近安排每天起止点 |
| 还有什么想让我知道的？ | `travelerNote` | 自由文本 | 兜底，接住一切没覆盖的诉求 |

---

## 4. 字段去向小结（与 [04 数据模型](04-architecture-and-data-model.md) 对齐）

- **专属结构化字段**：`destination` `days` `departureDate` `pace` `mustVisit` `avoid` `companions` `budgetTier` `budgetNote`。
- **软性标签塞 `travelerTags`**（作息 / 兴趣 / 怕排队 / 交通偏好等 chip 选择）。
- **任何没覆盖的**塞 `travelerNote` 自由文本。
- 收集态在对话里用 `<slots>…</slots>` 回传（见 [05 §3.2](05-butler-prompt-design.md)），`ready` 为 `destination`+`days` 是否齐。

## 5. 待验证
- 体验核心 5 问全问会不会太长？可能要砍到 2–3 问 + 一句「其余我先替你拿主意」。
- chip 选项措辞与数量，上线后看真实点选率调整。
- `companions=带娃/带爸妈` 时节奏是否要自动降一档（强约束 or 仅提示）。
