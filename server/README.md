# 丸丸自建后端

当前版本使用用户名和密码，不需要 Supabase、短信或邮箱。Node.js HTTP 服务复用 `api/ai.ts`，SQLite 保存账号、会话、行程、账本、打卡和私有照片。前端所有业务请求都走同源 `/api`。

## 本地运行

需要 Node.js 22.13+、pnpm。Node 22 的内置 SQLite 会显示实验性提示。

```sh
pnpm install --frozen-lockfile
pnpm backend:dev
# 另一个终端
pnpm dev
```

打开 http://localhost:5173 。开发代理转发到 `127.0.0.1:3001`。不要随意更改域名或端口：写请求的 Origin 必须匹配 `PUBLIC_ORIGIN`，默认 `http://localhost:5173`。

`.env.local` 仅在服务端读取。所需参数见 `server/env.example`；AI 实际生成需要 `DEEPSEEK_API_KEY`，图片识别及天气/地图增强复用原 AI 接口的可选参数。没有模型密钥也能注册、登录、保存数据。

```sh
pnpm test
pnpm build
# 单进程同时服务 dist 和 API，浏览器访问 localhost:3001
PUBLIC_ORIGIN=http://localhost:3001 pnpm start
```

## 账号和数据规则

- 账号 4–20 位，仅英文字母或数字；可纯字母或纯数字，统一转小写，数据库约束唯一。
- 密码 8–64 个 Unicode 码点，允许符号；随机盐加 scrypt（N=32768/r=8/p=1），不存明文。
- 登录使用随机会话令牌，数据库只存哈希。Cookie 为 HttpOnly、SameSite=Strict，生产环境还使用 Secure 和 `__Host-` 前缀；有效期 7 天。
- 注册展示一次恢复码。恢复密码会轮换恢复码、撤销账号全部会话，必须重新登录。密码与恢复码都丢失时不支持自助找回。
- 所有数据与图片的读写都由服务端按会话用户 ID 隔离，不接受客户端指定 owner。
- 登录/注册/恢复有持久化限流，注册每来源每天最多 5 次；AI 每账号 10 分钟最多 10 次，全站每天最多 200 次，并发最多 4。
- 不信任 X-Forwarded-For。反向代理下网络来源限额由所有访客共享，这是保守的单机上限；如需按真实访客 IP 扩容，先配置可信代理和边缘限流，不能直接信任任意转发头。
- 每账号最多 2000 条业务记录；照片压缩为 JPEG，单张最多 2MB，每账号 50MB。未引用照片超过一天后自动回收。
- 旧 Supabase 账号、数据、短信与微信配置不做迁移或删除。自建站的新账号不能凭同名访问旧账号数据。历史微信/短信代码仅作保留，新 HTTP 服务不挂载这些路由。

## 上线前

当前只完成本地实现，未购买服务器、未发布。Vercel 原有 serverless 发布方式不能直接运行这个持久化单机后端。

使用带持久磁盘的 Linux 服务器，在 HTTPS 反向代理后运行一个 Node 进程。`NODE_ENV=production`、`PUBLIC_ORIGIN=https://实际域名` 必填，`HOST=127.0.0.1`。不要把数据库文件、服务端代码或 `.env.local` 放到公开静态目录。生产进程使用专用低权限用户，进程管理器负责重启；`data/` 和备份只对该用户可读写。

构建入口 `pnpm build`，运行入口 `pnpm start`。发布前仍需核验仓库、分支、差异、域名、HTTPS、代理、备份、真实 AI 调用和磁盘空间，然后由用户确认具体流程。

安全一致性备份：`node server/backup.mjs /绝对路径/备份.sqlite`。SQLite `VACUUM INTO` 创建一致性快照，目标必须不存在。备份包含用户数据，只能存放在私有目录；建议每日备份并定期验证可恢复性。回退时停止进程，保留当前数据和备份，再恢复旧代码；需要恢复数据库时在进程停止后处理数据库及其 WAL/SHM 文件。不要在运行中直接覆盖数据库。

测试使用临时数据库和模拟模型响应，覆盖真实 HTTP 注册、会话、恢复码轮换、持久化重启、跨用户隔离、跨站请求和限流。真实模型费用、线上 HTTPS 与生产备份恢复仍需部署环境验收。

## 导入已有行程

网页“导入已有行程”支持 PDF（最多15页，扫描页使用OCR）、Word .docx（正文文字，不提取嵌入图片）、TXT/Markdown 和 JPG/PNG/WebP。单文件15MB、提取文字2万字、单次行程15天；原文件在浏览器读取，用户核对后仅把文字发给受会话及限流保护的 `/api/ai` import 操作。整理不调用路线优化或事实补全链路，结果经现有行程结构校验后在前端展示并自动保存；识别有误可先编辑文字。解析器按需加载，OCR首次运行需要下载语言资源。旧 .doc 不支持，请转换为 .docx 或 PDF。
